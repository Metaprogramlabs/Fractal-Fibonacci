# Changelog

## [1.0.0] - 2026-10-26

### Added
- Fractals (3 or 5 bar) with an adjustable confirmation period, marked with gray triangles
- Dealing range built from the latest fractals, updated when a new fractal breaks it
- Fibonacci levels 0, 0.5 and 1 with labels (Discount, Equilibrium, Premium)
- Separate menu group for every level: color, width and style
- Default style: levels 0 and 1 gray, solid, width 1; level 0.5 red, dashed, width 1
- Imbalances (fair value gaps): the latest N gaps as boxes, mitigated gaps stop extending
- Label size and label offset settings
